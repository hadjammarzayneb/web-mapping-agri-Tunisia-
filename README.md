# 🗺️ Web Mapping Agri Tunisia

A web mapping application for Tunisian agriculture built with OpenLayers and GeoServer.

## 📌 Overview

The application displays agricultural data layers (olive trees) on an interactive map of Tunisia using WMS services from GeoServer.

## ⚙️ Technologies Used

- HTML / CSS / JavaScript
- OpenLayers
- GeoServer (WMS)
- OpenStreetMap (base layer)
- Layer Switcher control

## 🚀 How to Use

1. Clone the repository
2. Set up GeoServer locally on localhost:8080
3. Publish the layer cite:Oliviers_en_Tunisie_(Superficie)
4. Open index.html in your browser
